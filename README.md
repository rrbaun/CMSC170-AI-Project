# Neural Three - AI Project

**Proposed Dataset:** The Number of Registered Deaths by Age Group, Sex, Region of Usual Residence and Cause of Death (Philippines: 2024)

The project aims to analyze regional mortality distribution patterns across the Philippines in 2024 and classify public health risk tiers based on demographic factors (age group, sex) and causes of death.
